# Sketch Duel

A two-way drawing game against a neural network, played in the browser.

- **AI draws, you guess**: a [Sketch-RNN](https://arxiv.org/abs/1704.03477)
  model (Magenta's pretrained 1024-unit "large" models) invents a drawing of a
  mystery word stroke by stroke; type your guess before time runs out.
- **You draw, AI guesses**: draw the word you're given; a CNN trained on
  Google's Quick, Draw! data calls out its top guesses with confidence and wins
  the round once it's at least 40% sure of the right word.

Six rounds alternate between the two. Points go to a shared team score:
50 for a correct guess plus up to 50 more for speed.

## Play

Serve the `web` folder and open it in a browser:

```bash
cd web && python3 -m http.server 8765   # then open http://127.0.0.1:8765
```

There's no build step and no backend; any static file server works.
Double-clicking `web/index.html` also works: both AI threads were checked to
start from a `file://` page (a full game has only been played over http).

An internet connection is needed: the AI's drawing models (~11 MB per word)
download from Google Cloud Storage. The first one starts downloading while
you're on the start screen, and each later AI drawing is prepared in the
background during the round before it. The guessing model is bundled in
`web/js/classifier-weights.js`.

## How it fits together

```
web/
  index.html, css/style.css
  js/sketch-rnn.js            loads Sketch-RNN models and samples drawings (plain JS, same math as @magenta/sketch)
  js/ai-workers.js            runs both networks in background threads (drawing and guessing)
  js/classifier.js            guesses drawings: rasterize to 28x28 + CNN forward pass
  js/classifier-weights.js    trained CNN, int8 (generated by training/export.py)
  js/words.js                 word display, aliases, typo-tolerant guess checking
  js/board.js                 canvas: AI animation + player drawing
  js/game.js                  rounds, timers, scoring, results
  dev/check-model.html        compares js/sketch-rnn.js with the official library
  vendor/magentasketch.js     @magenta/sketch 0.2.0 (Apache 2.0), used only by dev/check-model.html
training/
  words.txt                   the 95 words that have both a Sketch-RNN model and Quick, Draw! data
  download_data.py            samples Quick, Draw! drawings per word (HTTP range requests)
  raster.py                   stroke -> 28x28 image (mirrored by classifier.js)
  prepare_data.py             builds train/val arrays, incl. half-finished drawings
  train.py                    trains the CNN (PyTorch, uses Apple GPU if present)
  export.py                   folds BatchNorm, quantizes to int8, writes classifier-weights.js
  test_classifier.js          checks the JS forward pass against the Python one
```

## How the AI's drawings are kept clear

- **Large models.** Google's 1024-unit Sketch-RNN models were trained for
  1.7-2.6M steps on 80-210k drawings per word, versus 512 units for the small
  set that magenta-js demos use.
- **Low sampling temperature** (Easy 0.1, Normal 0.15, Hard 0.3), so the model
  sticks to typical shapes instead of improvising.
- **Best of several.** The game samples up to 6 / 4 / 2 drawings (by
  difficulty), scores each with the classifier, and shows the clearest one,
  stopping early once one is at least 90% recognizable.

Measured on 10 words x 8 samples, "recognized" meaning the classifier's top
guess is the right word:

| Setup | Recognized | Mean confidence | Best of 4 |
|---|---|---|---|
| Small models, temperature 0.3 (old Normal) | 82.5% | 0.72 | 95% (0.87) |
| Large models, temperature 0.3 (Hard) | 90.0% | 0.81 | 100% (0.99) |
| Large models, temperature 0.15 (Normal) | 92.5% | 0.84 | 100% (0.99) |
| Large models, temperature 0.08 | 88.7% | 0.81 | 100% (0.99) |

Below about 0.1 the model starts looping and gets worse. Difficulty also
changes how much time you get and how many letter hints show.

## Retraining the guesser

```bash
cd training
python3 download_data.py     # ~490 MB into data/raw (95 words + variant categories)
python3 prepare_data.py      # ~1 GB into data/dataset/ (1.39M images)
python3 train.py             # PyTorch, uses the Apple GPU if present
python3 export.py            # writes ../web/js/classifier-weights.js
node test_classifier.js      # JS/Python parity check
```

`sources.py` lists the extra Quick, Draw! categories mixed into some words so
the guesser knows other ways people draw them (ceiling fans for "fan", smiley
faces for "face", pickup trucks for "truck", school buses for "bus", plain
clocks for "alarm clock").

Requires Python 3 with `numpy`, `pillow` and `torch`. `data/` can be deleted
afterwards; the game only needs `web/`.
